# Executive Sales & Revenue Dashboard

An interactive Tableau dashboard built to analyze multi-year retail sales data, tracking revenue trends, profit margins, and regional performance. 

* **Live Dashboard:** [View on Tableau Public](https://public.tableau.com/views/ExecutiveSalesRevenueDashboard/Dashboard1)
* **Tools Used:** Tableau, Excel, SQL

---

## Overview
This project explores retail sales performance to help stakeholders quickly identify top-performing product categories and regional profit drivers. 

## Key Findings
* **Seasonality:** Revenue spikes consistently during Q4, mirroring standard retail holiday trends.
* **Profitability Drag:** High shipping discounts in specific regions heavily eroded net margins despite strong top-line revenue.
* **Regional Performance:** The West territory led in net profit contribution.

## Data & Exploration
1. Data was modeled and cleaned to track sales vs. profit across categories.
2. Use the live Tableau Public link to filter dynamically by region, category, and date.
